詰碁はどれも「青で囲んだ白の連は取られるか」の問題です。盤は普通の碁盤ではなく、2
列・3
列しかない細長い盤、端がねじれてつながるメビウスの帯、三角格子や蜂の巣などです。普通の碁の感覚
(呼吸点が 3 つあれば安心、2 つなら危ない)
が当てにならない局面だけを選んでいます。

- **黒** — 白の連を取れば勝ち。
- **白** — 黒がもう取れなくなれば (逃げ切れば) 勝ち。

手番は問題ごとに決まっていますが、どちらを持つかは自分で選びます。勝てると思う側を選んで、CPU
と最後まで打ってください。手番の側が勝つとは限りません。

問題ごとにアドレスが変わるので (`/tsumego?p=strip-1`
など)、「この問題を共有」やアドレスバーの URL で特定の問題を人に送れます。

## CPU の読み (`solve`)

決められた手数 (読みの深さ) までの手を、双方とも最善で読み切ります。
読む手は、人が石の取り合いを読むときと同じく絞っています。

- **攻める側** — 狙う連の呼吸点。呼吸点が 2 つ以下なら、その隣の点も
  (ゲタはそこに打つ)。
- **守る側** — 狙われた連の呼吸点、取れそうな (呼吸点が 2 つ以下の)
  相手の石の呼吸点、それにパス。取れそうな石は、狙われた連に接するものだけでなく、その呼吸点の隣にある味方の連に接するものも数えます
  (取って味方とつながれば逃げ道になるため)。

攻める側は、深さ以内に取れると読み切れたときだけ「取れる」とします。
呼吸点が多すぎて深さ以内に詰められない連は、その場で「逃げ切り」です。

CPU はあなたの反対側を持ち、手番が来るたびにこの読みを走らせます。

- CPU
  が白なら最善の受けを打ちます。白がもう助からないときは、打てる手をすべて試して一番長く粘る手
  (黒に最も多くの手数をかけさせる手)
  を打ちます。並んだら、石を取る手、呼吸点を多く残す手、連を大きくする手の順に選びます。
- CPU
  が黒なら、最も早く取れる追い方をしてきます。取れないときも、呼吸点を最も減らす手で粘ります。

白が取られたら黒の勝ち、黒の手番で黒がもう取れないと読めたら白の勝ちです。間違えた手を打っても「不正解」にはなりません。CPU
がその手に応じるので、決着まで打ち続けられます。負けたら「反対側で挑戦」で、もう一方の側を持って最初から打てます。

「ヒント」は、打てる手を一つずつ試し、打った後に CPU
が相手側で読んでもあなたの側が勝つ手を示します。黒なら、その中で最も早く取れる手です。ヒントが出ないときは、その局面からはあなたの側に勝ち筋がありません。

## 続きを検証

決着がついたら「続きを検証」で、その局面から黒白どちらの手も自由に打てます。

- 打つたびに、手番側から読んだ結果 (黒が深さ以内に取れるか) と、読みの最善手
  (青い印) が出ます。
- 「CPU
  が打つ」は手番側の最善手を打ちます。押し続けると読み筋を順にたどれます。黒が取れない局面では、黒は狙う連の呼吸点を最も減らす手を打つので、どう追っても逃げられる理由が見えます。
- 「待った」は 1 手ずつ戻ります。問題中に打った手まで戻れます。

## 問題の作り方

問題はランダムに石を置いた局面から、読みで次の条件を満たすものだけを選んでいます
(`tools/gen_tsumego.ts`)。

- 眼の感覚に反する: 黒が勝つなら白の呼吸点は 3 つ以上、白が勝つなら 2 つ以下
- 盤ごとに、手番の側が勝つ問題と、手番なのに負ける問題を 1 つずつ
- 手番の側が勝つ問題は、パスすると負ける (急場である) うえに、勝てる初手が 2
  つ以下
- 黒が勝つ問題は、取るまでに黒が 3 手以上かかる (ただのアタリではない)

どの問題も、勝つ側でヒントどおりに打てば CPU に勝ち、負ける側では CPU
と同じ最も粘る手を打っても負けることを、テスト (`wasm/graph_go_test.ts`)
で確かめています。
